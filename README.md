## About This Project

**Green Event** is a modern, eco-friendly event management platform designed for organizers who care about the planet. This is the **client-side application** where users can:

- Browse upcoming green & sustainable events (tree plantation, clean-up drives, workshops, seminars, etc.)  
- Filter events by event types
- View detailed event info, organizer profile & real-time seat availability  
- Register for events with one-click RSVP  
- See impact stats (trees planted, CO₂ reduced, waste recycled)  

Built with performance, accessibility, and beautiful animations in mind – delivering a smooth and delightful user experience on mobile & desktop.

**Live Demo** → [https://green-event-client.vercel.app](https://green-event-msh.netlify.app/)  
**Backend Repo** → [github.com/Md-Shajib-Hossain/green-event-server](https://github.com/md-shajib-hossain/green-event-server-site)

## About This Project

**Green Event** is built for people who want to make a real impact on the planet. This client-side application allows users to:

- Discover eco-friendly events across Bangladesh  
- Filter by location, date, category & impact type  
- View detailed event pages with organizer info & real-time availability  
- Register instantly with secure authentication  
- Receive digital tickets & event reminders  
- Track personal contribution (trees planted, waste reduced, CO₂ saved)  
- Fully responsive & accessible on all devices  

> *"Every event is a chance to heal the planet."* – Let's grow a greener future together!

## Installation & Run Locally

```bash
# Clone the repository
git clone https://github.com/md-shajib-hossain/green-event-client-site.git

# Enter project directory
cd green-event-client

# Install dependencies
npm install
# or
yarn

# Create .env file (ask for env variables)
cp .env.example .env.local

# Start development server
npm run dev
